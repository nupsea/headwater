# Radiology Workflow Simulation Dataset — Attribution

License: **CC BY 4.0** (redistributable with attribution).

Source: Mendeley Data — "Radiology Workflow Simulation Dataset: Synthetic Patient
Flows, Event Logs, Exam Records, and Resource Utilization Metrics based on a Published
Radiology Workflow Model."
DOI: 10.17632/jsg8c4yhxy.1
URL: https://data.mendeley.com/datasets/jsg8c4yhxy/1

Synthetic data generated via the CrogMagnon discrete-event simulation engine
(NEAT-AMBIENCE Project, University of Zaragoza), parameterized from a peer-reviewed
description of a Belgian hospital radiology department. Covers a 7-day period beginning
2023-01-01. No real patient data.

Files: cases.csv (patient-level), exams.csv (exam-level), events.csv (event log),
dataset_details.txt, intended_uses.txt.
